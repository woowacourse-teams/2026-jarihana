# 집중 부하에서 커밋된 글과 SSE 대조

두 JVM을 새로 시작한 뒤 서버 2대, 방 128개, 구독 연결 1,024개, 초당 800건으로 25초 동안 재실행했다.
본 측정의 집중 부하 케이스는 같은 JVM에서 무채팅과 분산 부하를 먼저 수행했다.

| 모드 | HTTP 성공 / 시도 | DB 조회 시점 저장 | SSE 기대 전달 | 관측 종료까지 미도착 | 중복 |
| --- | ---: | ---: | ---: | ---: | ---: |
| poll | 4,106 / 20,000 | 17,802 | 142,416 | 49,428 | 0 |
| notify | 4,101 / 20,000 | 18,964 | 151,712 | 61,446 | 0 |

클라이언트는 마지막 HTTP 성공 또는 타임아웃 뒤 2.2초 동안 더 관측했다. 이후 DB에서 읽은 ID를 SSE 관측과 대조했다.
관측 종료와 DB 조회 사이에 커밋된 글도 미도착 집계에 들어갈 수 있다. 측정 범위는 종료 시점까지의 도착이며 장시간 뒤 재전달 여부는 측정하지 않았다.
