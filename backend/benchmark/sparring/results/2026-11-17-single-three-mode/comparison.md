# 단일 인스턴스에서 서버 폴링과 두 NOTIFY 방식 비교

같은 JAR, Docker 이미지, 힙 한도 384 MiB와 JDBC 풀 10개를 사용했다. 각 조건에서 세 모드를 순차 실행했고, 매번 새 DB와 백엔드 컨테이너 하나를 띄웠다. 부하 생성은 25초다. 두 NOTIFY 방식은 SSE 조회 1초와 보완 조회 5초를 공유한다. 노티파이 5초는 저장 커밋마다 발행하고 노티파이 1초는 방별로 묶어 발행한다.

CPU 100%는 논리 코어 하나다. DB 메모리는 컨테이너 전체 사용량이며 파일 캐시를 포함한다. 백엔드 메모리는 표본 최대 RSS다. 큐 락 추적과 JDBC 요청별 타임라인은 지속 채팅에서 수집했다.
