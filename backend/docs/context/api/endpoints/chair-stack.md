# 의자 쌓기

기본 경로는 `/api/games/chair-stack`이다. 비회원도 모든 기능을 이용할 수 있다. 변경 요청은 공통 CSRF 쿠키와 헤더가 필요하다. 응답에는 `Cache-Control: no-store`를 적용한다.

| 메서드 | 경로 | 동작 |
| --- | --- | --- |
| GET | `/runs/current` | 현재 판과 내 최고 기록을 조회한다. 게스트 쿠키가 없으면 발급한다. 회원 화면은 `?member=true`로 세션 확인을 요청할 수 있다. |
| POST | `/runs` | `member`, `nickname`, `previousRunId`, `requestId`로 새 판을 시작한다. |
| POST | `/drops` | `member`, `runId`, `turn`, `x`, `requestId`로 의자 하나를 놓는다. |
| GET | `/rankings` | 공개 랭킹을 `cursor`, `size`로 조회한다. 기본 20건, 최대 100건이다. |

현재 판, 시작, 배치의 `data`에는 `guest`, `nickname`, `bestScore`, `run`이 있다. `run`은 `id`, `placements`, `active`, `preview`, `failedLayer`, `finished`, `motion`을 포함한다. 새 판의 `run.physics`에는 화면에 놓인 의자의 `chairs`, `active`, `preview`, 낙하 시작 높이와 발판 너비가 있다. 의자 위치는 `x`, `y`, 라디안 `angle`로 표현한다. `flat`이 참이면 평면 실루엣과 같은 직사각형 충돌 모양을 쓴다. `sideProfile`이 참이면 옆에서 본 등받이, 좌판, 앞다리의 실루엣을 사용한다. 원근 그림을 사용하는 이전 판의 `verticalShear`는 가로 중심 기준 세로 보정값이다. 새 배치 응답의 `frames`는 브라우저가 충돌과 무너지는 과정을 재생하는 데 사용한다. 새로고침하거나 같은 배치 요청을 다시 보내면 마지막으로 확정된 자세를 반환한다.

게스트 닉네임은 정규화한 한글, 영문, 숫자와 공백 2~12자로 받는다. 회원 닉네임은 서버가 서비스 프로필에서 읽는다. `member`가 참이면 회원 세션이 있어야 하며, 만료되면 공통 세션 갱신 경로를 이용한다. 게스트는 서버가 발급한 HttpOnly 쿠키로 식별한다. 쿠키 원문은 저장하지 않는다.

- 기존 판을 교체할 때는 `previousRunId`를 보낸다. 같은 플레이어의 새 판 시작은 1초 간격으로 제한한다. 마지막 확정 동작 이후 24시간이 지나면 판이 만료된다.
- `turn`은 이전까지 성공한 배치 개수, `x`는 -18~18의 정수다. 새 판의 의자 색과 시작 방향은 판 ID와 차례를 바탕으로 서버에서 정한다. 서버의 dyn4j 물리 엔진이 의자의 부분별 밀도, 중력, 마찰, 충돌을 적용하고 받침과 연결돼 남은 탑을 확인한다. 첫 의자와 판마다 무작위로 선택한 세 번째 또는 네 번째 의자가 똑바로 선 방향으로 나오고, 두 번째 의자는 뒤집혀서 나온다. 초반에는 낮게 떨어지고 빠르게 안정되며, 쌓을수록 낙하 높이와 방향 변화가 커진다. 진행 중인 판은 시작할 때의 물리 규칙으로 이어진다.
- 같은 시작 요청이나 마지막 배치 요청을 다시 보내면 이미 확정된 판을 반환한다. 차례가 맞지 않으면 409, 현재 플레이어가 소유한 유효한 판이 아니면 404를 반환한다.
- 물리 엔진을 사용하는 판의 배치 요청에는 `adjustment`를 선택적으로 보낼 수 있다. `angleDegrees`는 화면에서 시계 방향으로 재는 -180~180의 정수 각도이고, `mirrored`는 회전하기 전 의자 이미지의 좌우 반전 여부다. 서버는 이 자세로 낙하를 시작하고 최종 자세와 반전을 저장한다. 생략하면 의자에 배정된 시작 자세를 사용한다.
- 새 판의 의자는 첫 의자와 같은 가로와 세로 크기를 쓴다. 좌판과 등받이는 테두리와 가로대를 각각 계산해, 다른 의자의 다리가 틈에 들어가 맞물릴 수 있다.
- 무너진 판과 100개 완주 판은 종료된다. 1점 이상으로 끝난 판만 기록에 반영한다. 회원과 게스트 모두 플레이어당 최고 기록 한 건을 가진다. 점수가 같으면 공동 순위이며 달성 시각과 내부 ID 순으로 표시한다.
- 랭킹의 `items`, `me`는 `rank`, `nickname`, `guest`, `score`를 반환한다. 기록이 없으면 `me`는 null이다.

물리 규칙이 바뀌어도 최고 기록은 이어진다.
