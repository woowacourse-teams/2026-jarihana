# 도메인 불변식

> 상태: 저장소 최신 설계 기준
>
> 구현·테스트·Swagger/OpenAPI와 충돌하면 임의로 해석하지 않고 차이를 보고한다.

이 문서는 구현 방법이 아니라 여러 모델 또는 여러 인스턴스 사이에서 항상 참이어야 하는 도메인 규칙을 정리한다.

> 이 절에는 “무엇이 항상 참이어야 하는가”만 적는다. 모델 하나의 필드 형식과 값 유효성은 `model/` 아래 상세 문서에서, 요청·이벤트에 따른 처리 흐름은 `business-policies.md`에서 다룬다. DB 제약, 락, 배치 같은 구현 수단은 별도 기술 구현 페이지에서 다룬다.

## Member

| 불변식                                                                                                    |
| --------------------------------------------------------------------------------------------------------- |
| `CREW` 회원은 같은 기수에서 `crewName`을 중복 사용할 수 없다.                                             |
| `COACH` 회원끼리는 `crewName`을 중복 사용할 수 없고, 코치명은 모든 `CREW` 회원의 크루명과 중복될 수 없다. |

## Group

| 불변식                      |
| --------------------------- |
| 그룹 이름은 중복될 수 없다. 종료된 그룹의 이름 재사용 여부는 이 전역 유일성 정책에 따라 허용하지 않는 것으로 통합하되, 팀이 부분 유일성으로 바꾸려면 정책을 다시 결정해야 한다. |

## Group · GroupRecruitment

| 불변식                                     |
| ------------------------------------------ |
| `Group`과 `GroupRecruitment`는 1:N 관계다. |

## Member · GroupRecruitment · Registration

| 불변식                                                                                                                                             |
| -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 한 회원은 하나의 모집 공고에 하나의 신청만 가진다.                                                                                                 |
| 승인 또는 거절된 신청이 있는 경우 같은 공고에 재신청할 수 없다. 또한 같은 그룹에 `PENDING` 신청이 존재하면 해당 그룹의 다른 공고에 신청할 수 없다. |
| 기존 신청이 `APPROVED` 또는 `REJECTED`로 결정된 뒤에는 다른 공고에 신청할 수 있다.                                                                 |

## Member · GroupMember

| 불변식                                               |
| ---------------------------------------------------- |
| 같은 회원의 같은 그룹 내 `GroupMember`는 하나뿐이다. |

## Group · GroupMember

| 불변식                                               |
| ---------------------------------------------------- |
| 활동 중인 그룹에는 `LEADER`가 정확히 한 명 존재한다. |
