# 오목

게임은 모임 소속과 독립적이며 가입 완료 회원 두 명이 참가한다.

- 방 공개 여부는 공개/초대 전용, 규칙은 자유룰/렌주룰 중 생성 시 정하고 이후 고정한다.
- 회원은 대기 또는 진행/결과 상태 방 하나에 참여한다. 두 명이 준비한 뒤 방장이 시작한다. 준비만으로 대국이나 타이머가 시작되지 않는다. 첫 흑백은 무작위,
  재대국은 직전 판의 흑백을 교대한다. 무르기, 관전과 대전 채팅은 제공하지 않는다.
- 15x15 판에서 자유룰은 흑백5개 이상, 렌주룰은 흑 정확히5개와 백5개 이상으로 승리한다.
- 렌주 흑의 쌍3, 쌍4, 장목 착수는 거절한다. 동시에 정확한5목을 완성하면 승리를 우선한다.
  삼의 정의는 합법적인 후속 수로 양 끝에서 정확한5목을 완성할 수 있는 열린 사가 되는 경우다.
  후속 수에서 동시에5목을 만드는 경우는 삼으로 세지 않으며, 후속 수의 금수도 재귀 검사한다.
- 대회 오프닝은 적용하지 않는다. 금수 거절 후에도 시간은 흐르며 현재 차례를 유지한다.
- 매 차례60초. 연결 종료/탭 전환 중에도 서버 기한은 유지하고 경계 시각부터 시간패다.
- 승리 없이 판이 가득 차면 무승부다. 기권은 상대 승리다.
- 대기 중 상대가 나가면 준비를 초기화하고 빈자리를 다시 모집한다. 대기방장이 나가거나
  대전/결과 상태에서 누군가 나가면 방을 닫는다. 진행 중 나가기는 기권 결과도 보존한다.
- 대기와 결과 상태의 마지막 실제 활동 후30분이면 닫는다. 조회/재연결만으로 수명을 늘리지 않는다.
- 방은 `WAITING -> PLAYING -> FINISHED -> PLAYING`으로 진행하며 종료된 방은 재개하지 않는다.
- 판의 저장 데이터는 색과 좌표만 가진다. 캐릭터, 이미지와 애니메이션은 표현 계층의 외형이다.

## 대전기록과 랭킹

- `GomokuGame`은 시작한 한 판을 소유한다. 시작 시 참가자 ID와 이름, 흑돌 회원, 규칙을 보존하고 종료 시 승자, 종료 사유, 최종 착수 수와 종료 시각을 확정한다. 재대결이나 방 종료로 이전 결과를 수정하지 않는다. 기록 삭제 기능은 제공하지 않는다.
- `(room_id, game_number)`로 한 판의 기록을 하나로 제한한다. 기록에는 soft delete를 적용하지 않으며 해당 유일 제약과 충돌하는 재생성도 없다. 방 잠금과 같은 명령 트랜잭션에서 생성/완료한다. DB 조회용 복제본이나 별도 통계 테이블을 만들지 않는다.
- 기록 기능이 있는 버전에서 시작한 모든 판을 수집한다. 수집을 끄는 설정은 없다. 기능 적용 전의 진행/완료 판과 대기 취소는 소급 집계하지 않는다. 공개/비공개, 착수 유무와 관계없이 기권과 시간패도 포함한다.
- 회원 본인의 완료 기록만 조회한다. 승률은 `승수 / 전체 완료 판수 * 100`을 소수 첫째 자리로 반올림하며 무승부를 분모에 포함한다. 완료 판이 없으면 승률은 null이다.
- 회원 전용 누적 승수 랭킹은 완료 대국이 있는 비탈퇴 회원을 대상으로 한다. 승수 내림차순, 총 판수 오름차순(같은 승수에서 높은 정확한 승률 우선), 회원 ID 오름차순의 순번이다. 반올림한 표시 승률로 정렬하지 않는다. 0승의 동률에도 총 판수와 ID로 안정적으로 정렬한다.
- 상대 이름은 판의 시작 시점 값, 랭킹 이름과 프로필은 현재 회원 정보다. 랭킹은 승/패/무 집계만 공개하며 다른 회원의 개별 대국 목록은 제공하지 않는다.
- 기록과 랭킹은 DB에서 필터/집계/정렬/커서 조회한다. 랭킹은 조회 시점 결과이므로 대국이 추가된 사이의 다음 페이지에서는 순위가 바뀔 수 있다. 화면 재진입/복귀 시 처음부터 갱신한다.

API: [오목 계약](../../api/endpoints/gomoku.md).
규칙 근거: [RIF 국제 규칙](https://www.renju.net/rifrules/). 금수에서 패배시키는 대신 착수를
차단하는 점과 대회 오프닝을 생략하는 점은 서비스용 변경이다.

## 게임방 채팅

좌석의 participationId와 chatStartSequence가 참가 회차와 대화 조회 하한을 결정한다. 메시지는 방별 증가 순번과 회차별 clientMessageId로 중복 전송을 막으며 방 종료 시 본문을 삭제한다. 참가자의 새 채팅만 방 활동 시각을 갱신하고 판 revision과 착수 기한은 유지한다.

## 공개 대국 관전

관전 입장 이력과 SSE 접속 lease를 별도로 저장한다. 방 잠금 안에서 입장 순번을 확정하고 모든 채팅 조회에 하한을 적용한다. 15초마다 갱신하는 45초 lease가 있는 회원을 중복 제거해 집계하며 참가자를 제외한다. 관전 활동은 판 revision과 착수/유휴 기한을 변경하지 않는다. senderRole은 서버가 정한다.
