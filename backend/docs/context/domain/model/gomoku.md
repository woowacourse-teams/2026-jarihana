# 오목

게임은 모임 소속과 독립적이며 가입 완료 회원 두 명이 참가한다.

- 방 공개 여부는 공개/초대 전용, 규칙은 자유룰/렌주룰 중 생성 시 정하고 이후 고정한다.
- 회원은 대기 또는 진행/결과 상태 방 하나에 참여한다. 두 명이 준비한 뒤 방장이 시작한다. 준비만으로 대국이나 타이머가 시작되지 않는다. 첫 흑백은 무작위,
  재대국은 직전 판의 흑백을 교대한다. 무르기, 관전, 랭킹과 대전 채팅은 제공하지 않는다.
- 15x15 판에서 자유룰은 흑백5개 이상, 렌주룰은 흑 정확히5개와 백5개 이상으로 승리한다.
- 렌주 흑의 쌍3, 쌍4, 장목 착수는 거절한다. 동시에 정확한5목을 완성하면 승리를 우선한다.
  삼의 정의는 합법적인 후속 수로 양 끝에서 정확한5목을 완성할 수 있는 열린 사가 되는 경우다.
  후속 수에서 동시에5목을 만드는 경우는 삼으로 세지 않으며, 후속 수의 금수도 재귀 검사한다.
- 대회 오프닝은 적용하지 않는다. 금수 거절 후에도 시간은 흐르며 현재 차례를 유지한다.
- 매 차례60초. 연결 종료/탭 전환 중에도 서버 기한은 유지하고 경계 시각부터 시간패다.
- 승리 없이 판이 가득 차면 무승부다. 기권은 상대 승리다.
- 대기 중 상대가 나가면 준비를 초기화하고 빈자리를 다시 모집한다. 대기방장이 나가거나
  대전/결과 상태에서 누군가 나가면 방을 닫는다. 진행 중 나가기는 기권 결과도 보존한다.
- 대기와 결과 상태의 마지막 실제 활동 후30분이면 닫는다. 조회/재연결만으로 수명을 늘리지 않는다.
- 방은 `WAITING -> PLAYING -> FINISHED -> PLAYING`으로 진행하며 종료된 방은 재개하지 않는다.
- 판의 저장 데이터는 색과 좌표만 가진다. 캐릭터, 이미지와 애니메이션은 표현 계층의 외형이다.

API: [오목 계약](../../api/endpoints/gomoku.md).
규칙 근거: [RIF 국제 규칙](https://www.renju.net/rifrules/). 금수에서 패배시키는 대신 착수를
차단하는 점과 대회 오프닝을 생략하는 점은 서비스용 변경이다.
