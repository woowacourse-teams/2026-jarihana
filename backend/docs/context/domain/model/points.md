# 포인트

포인트는 회원이 모임과 게임 활동으로 모으는 서비스 내 보상이다. 보상 활동과 지급액은 [비즈니스 정책](../business-policies.md#포인트-적립)에서 관리한다.

## 모델과 책임

| 모델 | 저장 위치 | 역할 |
| --- | --- | --- |
| 지갑 | `point_wallet` | 회원별 확정 잔액을 관리한다. PostgreSQL `BIGINT`와 Java `long`을 사용한다. |
| 지급 작업 | `point_reward` | 수령 회원, 적립 사유, 원본 키, 선택 범위 키, 정책 버전, 지급액, 활동 시각과 처리 상태를 보존한다. |
| 원장 | `point_ledger` | 확정된 지급 작업의 ID, 회원, 금액과 확정 시각을 기록한다. |
| 모임 생성 이력 | `point_group_origin` | 모임 ID, 최초 생성 회원과 생성 시각을 보존해 첫 구성원 합류 시 수령자를 식별한다. |
| 적립 규칙 | `PointRewardRule` | 사유 코드별 표시 이름, 지급액과 회원당 1회, 주간 한도, 범위 중복 같은 제한을 정의한다. |

지급 작업은 회원, 사유 코드, 원본 키로 식별한다. 원본 키는 지급의 근거가 된 활동 ID를 담는다. 범위 키는 사진 활동기록의 모임과 활동 날짜처럼 원본 활동 ID와 별개의 중복 범위가 필요할 때 쓴다.

## 지급 상태

| 상태 | 의미 |
| --- | --- |
| `PENDING` | 자격을 확인하고 지급을 예약했다. 처리 또는 재시도를 기다린다. |
| `COMPLETED` | 원장 기록과 잔액 반영이 확정됐다. |
| `SKIPPED` | 자격 또는 한도 조건에 맞지 않아 사유를 남겼다. |
| `NEEDS_REVIEW` | 자동 재시도 한도에 도달해 운영 확인을 기다린다. 기존 적립 한도 예약을 유지한다. |
