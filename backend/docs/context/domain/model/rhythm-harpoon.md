# 행성이의 리듬 작살 공식 도전

리듬게임의 기록 도전이다. 모임 소속과 독립적이며 가입 완료 회원 한 명이 혼자 한다.
연습과 따라 하기는 브라우저 안에서만 끝나고 서버에 남지 않는다.

## 판의 진행

- `RhythmChallenge`는 한 판을 소유한다. 회원이 난이도와 세균 이동 배속을 고르면 서버가 시드를 정해 `CREATED`로 만든다.
  배속은 1.0부터 3.0까지 0.25 단위이며 보이는 속도만 바꾸고 판정 시각에는 영향이 없다.
- 시작 요청을 받은 시각이 실제 경과 시간의 기준이다. `CREATED`는 5분 안에 시작하지 않으면 `INVALID(EXPIRED)`가 된다.
- 진행 중인 판은 클라이언트가 2초마다 보내는 입력 묶음으로만 바뀐다. 묶음에는 1부터 이어지는 순번, 곡 시작 기준 진행 시각과
  그 사이의 입력(방향 순번, 입력 지연 보정을 적용한 시각)이 들어 있다. 점수, 라이프, 판정 수는 받지 않는다.
- 같은 순번을 다시 받으면 계산하지 않고 현재 상태를 돌려준다. 순번을 건너뛰면 거절한다.
  입력 시각은 앞선 입력과 앞선 묶음의 진행 시각보다 앞설 수 없고 그 묶음의 진행 시각을 넘을 수 없다.
  서버가 이미 계산한 구간에 뒤늦게 입력을 넣어 돌진 중인 세균을 다시 잡는 것을 막는다. 첫 묶음은 앞선 입력만 본다. 한 묶음에는 입력을 400개까지 받는다.
- 일시정지는 없다. 진행 시각이 서버 경과 시간보다 3초 넘게 앞서면 `CLOCK_AHEAD`, 15초 넘게 늦으면 `LAGGED`,
  진행 중 30초 동안 묶음이 없으면 `STALE`, 클라이언트가 이탈(Esc, 탭 전환, 창 이탈)을 알리면 `ABANDONED`로 무효가 된다.
  무효인 판은 점수와 관계없이 기록과 랭킹에 넣지 않는다.
- 서버 계산에서 라이프를 모두 잃으면 `FINISHED`가 되고 그때의 점수와 판정 수가 기록이다. 클라이언트가 판이 끝났다고 알렸는데
  서버 계산이 아직 살아 있으면 그 뒤 입력이 없는 것으로 보고 끝까지 계산한다.
- 상태는 `CREATED -> PLAYING -> FINISHED` 또는 `INVALID`로만 움직이며 끝난 판은 다시 열지 않는다.

## 서버 재계산

- `RhythmEngine`은 프론트엔드 `engine.mjs`의 판정을 같은 연산 순서로 옮긴 것이다. 루프 배치, 템포 상승, 시드 기반 방향 섞기,
  계단 회전과 판정 폭, 헛공격, Uh oh, 라이프 감소와 완주 충전이 같다.
- 실제 루프 종료 시점에 Hardest는 하트 5개, Easy, Medium, Hard는 3개를 충전하며 최대 라이프를 넘지 않는다.
  다음 루프를 미리 배치할 때는 충전하지 않는다. 완주 전에 라이프를 모두 잃으면 부활하지 않는다.
  입력 묶음이 경계를 넘어 도착해도 피해와 충전을 발생 시각 순으로 처리하고, 저장된 묶음을 다시 계산해도 중복 지급하지 않는다.
  완주 충전은 `rhythm-harpoon-ranked-2`부터 적용했다.
- 판정 범위 밖의 입력은 헛공격으로 300점을 깎고 콤보와 라이프는 그대로 둔다. 따로 무시하던 구간(일찍 200~230ms, 늦게 150~180ms)은 없앴다.
  이 규칙은 `rhythm-harpoon-ranked-3`이며 판본마다 랭킹을 구분한다.
- 난이도별 단순화 채보와 계단 회전표는 프론트엔드 엔진이 만든 `rhythm-harpoon/ranked-chart.json`을 읽는다.
  채보, 판정, 라이프를 바꾸면 `frontend/scripts/export-rhythm-ranked-fixtures.mjs`로 채보와 대조 입력(`golden-replays.json`)을
  다시 만들고 규칙 판본(`rulesVersion`)을 올린다. 두 엔진이 대조 입력에서 같은 결과를 내는지 양쪽 테스트가 확인한다.
- 계산 상태는 진행 중인 판마다 메모리에 둔다. 서버가 다시 떴거나 순번이 맞지 않으면 저장한 묶음
  (`rhythm_challenge_batch`)을 순서대로 다시 계산한다. 같은 판의 묶음은 행 잠금으로 하나씩 계산한다.
- 브라우저가 보내는 입력 자체는 조작할 수 있다. 실시간 진행 검사는 미리 만든 입력을 한꺼번에 내는 것을 막지만 자동 입력 봇을
  막지는 못한다.

## 랭킹

- 난이도와 규칙 판본마다 회원별 최고 기록 한 판으로 순위를 매긴다. 점수가 같으면 먼저 끝난 판, 그다음 회원 ID 순이다.
- 탈퇴한 회원은 랭킹에서 뺀다. 이름은 회원의 `crew_name`, 프로필은 GitHub 아바타 주소다.
- 별도 랭킹 테이블 없이 `FINISHED` 판에서 계산한다. 규칙 판본이 바뀌면 새 판본의 랭킹이 비어 있는 상태로 시작한다.
