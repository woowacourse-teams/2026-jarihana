- [GitHub 작업 컨벤션](repository-conventions/github.md): 이슈, 제목
- [ADR 문서 컨벤션](repository-conventions/adr.md): 영역별 ADR과 교차 참조
- [커밋 컨벤션](repository-conventions/commits.md): 커밋 형식, 타입, 제목, 본문과 푸터
