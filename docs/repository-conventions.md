# 저장소 컨벤션

> 이 문서는 구속력 있는 팀 컨벤션 모듈이다.
> 인덱스: [team-convention.md](../backend/docs/team-convention.md)

## 문서 구성

카테고리별 세부 규칙은 다음 문서에서 관리한다.

- [Git 작업 컨벤션](repository-conventions/git.md): 브랜치, 보호·병합, PR
- [코드 리뷰 정책](repository-conventions/code-review.md): 파일럿 리뷰 기준, AI 작성 하네스, 담당자와 슬롯
- [GitHub 작업 컨벤션](repository-conventions/github.md): `gh` CLI, 이슈, 제목
- [ADR 문서 컨벤션](repository-conventions/adr.md): 영역별 ADR과 교차 참조
- [커밋 컨벤션](repository-conventions/commits.md): 커밋 형식, 타입, 제목, 본문과 푸터
- [DB 변경 규칙](database-changes.md): 구버전 호환성, Expand–Contract와 배포 전 PR 검토
