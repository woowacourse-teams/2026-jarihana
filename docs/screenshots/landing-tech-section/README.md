# 랜딩 기술 소개 장 스크린샷

`feat/landing-tech-section`(커밋 `3663b8d0`)의 랜딩 기술 소개 장 화면이다. PR 본문에서 참조하려고 보관한다.

- 캡처 날짜: 2026-10-29 (KST)
- 빌드: `npm run build`(Webpack production), 정적 서버로 `/land`를 띄움
- 브라우저: Playwright와 설치된 Edge 156.0.4314.50의 headless 실행, 배율 1, 언어 ko-KR, 동작 줄이기 꺼짐
- 화면 크기: 데스크톱 1280 x 900, 모바일 375 x 812
- 인증 API는 비로그인 상태의 401 응답으로 대신했고 실제 백엔드는 연결하지 않았다.

장마다 스크롤 위치를 코드로 옮긴 뒤 휠 입력 한 번으로 활성화하고, 도표는 재생이 끝난(`data-state="complete"`) 다음 찍었다.
모바일의 배포 시간(869px)과 칸 그림(939px) 장은 화면보다 길어 랜딩 스크롤 제어기가 두 번에 나눠 멈추며, 스크린샷은 첫 정착 위치다.
`capture-report.json`에서 두 화면 크기 모두 브라우저 pageerror 0건과 가로 넘침 없음을 확인했다.
실제 휠과 터치 스와이프, 실제 휴대폰 기기는 확인하지 않았다.
