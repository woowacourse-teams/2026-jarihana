# PR #571 비교 캡처

클레이 디자인 갱신 이미지 12장은 JPG 파일이다. 기존 PNG는 이전 비교 기록으로 보존한다.

- 선택, 싱글 플레이, 따라 하기: 코드 커밋 25ef995343b94916770a2c94df21ffd3de4230d9
- 연습 준비, 실행, 결과: 코드 커밋 5d0c992ea1a18871f80373830f6eb192c9286f0b
- 두 코드 버전의 차이는 판정 기준과 안내 문구이며, 클레이 디자인은 같다.
- 환경: 로컬 Webpack 개발 서버, ChatGPT in-app browser, 비로그인, 백엔드 미연결
- 데스크톱 viewport 1440x900, 모바일 viewport 390x844. 브라우저 스크롤바를 제외한 실제 콘텐츠 너비는 1425px와 375px다.
- 데스크톱은 현재 viewport, 모바일은 전체 페이지를 촬영했다. 푸터와 설정이 함께 포함될 수 있다.
- 음악, 채보, 스프라이트는 해당 커밋의 실제 파일이다. 게임 상태나 점수 데이터를 주입하지 않았다.
- lesson-playing-desktop.jpg는 들어보기 자동 시연이다. 실제 사용자 입력 통과를 의미하지 않는다.
- result 이미지는 키를 누르지 않아 라이프가 소진된 실제 결과다. 0점과 놓친 세균 10개는 의도된 촬영 상태다.
- 모바일 연습 화면의 document 너비와 scrollWidth가 모두 375px임을 확인했다.
- 백엔드 미연결로 인증 조회 프록시 오류가 발생한다. 실제 소리와 iOS 실기기는 확인하지 않았다.
- 이미지 저장과 PR 문서만 갱신했으며 이번 촬영 작업에서 코드나 테스트를 수정하지 않았다.

파일별 픽셀 크기, 해시와 코드 커밋은 capture-report-clay.json에 기록했다.
이미지는 코드 PR의 diff에 넣지 않고 docs/pr-571-clay-captures 브랜치에 보관한다.
