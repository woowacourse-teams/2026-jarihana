# 캡슐 받아치기 연출

## v11: 캡슐에 탄 작은 발언자

사용자가 제안한 캐릭터 연출을 실제 체험판에 적용하도록 승인했다. v10 커밋
`8c139f12`와 태그는 그대로 보존한다. 참고 화면은 localhost:5189/sparring의
`sparring-hose-duel.webp`: 검은 머리, 큰 머리와 작은 몸, 둥근 피부·의상,
회색 상의·청바지·백팩, 검은 옷·민트 사원증의 두 피규어다. 기존 이미지의
확인한 에셋은 이미지이므로 같은 특징을 가진 절차적 3D 피규어로 근사한다.

주 행동은 한마디 보내기. 정보 순서는 캐릭터 도착 → 말풍선 → 작성자·지난 대화
구분이다. Layout: 기존 통·미끄럼틀·양옆 말풍선 배치를 유지하고 3D 내용물과
출구 동작만 바꾼다. 투표·편 선택·기록·받아치기·입력·정지 조작은 유지한다.

통 안에서는 작은 캐릭터가 캡슐에 웅크려 있다. 미끄럼틀에서는 껍질의 물리
회전과 별개로 캐릭터가 몸을 기울이고 팔을 앞으로 들어 버틴다. 실제 받침대
충돌 뒤 뚜껑이 튀고, 아래 껍질은 작은 발언대가 되어 캐릭터가 빼꼼 올라온다.
새 글은 더 크게 일어나며 내 글은 짧게 손을 흔든다. 약 0.4초에 말풍선이 열린
뒤에는 읽을 수 있도록 동작을 잦아들게 한다. 퇴장할 때 안으로 들어가고 닫힌다.
받아치기는 기존 양쪽 충돌과 두 말풍선을 유지하며 두 발언자가 함께 나온다.

캐릭터 의상은 작성자 식별자에 따라 고정하고 편 변경에 따라 바꾸지 않는다.
투표 비율은 캡슐 껍질 색으로만 유지한다. 자동 배출 1.6~2.4초, 구르기 1개,
표시 4개 상한을 지킨다. 움직임 줄이기는 구르기·등장·손짓을 생략하고 정착한
캐릭터와 의견을 바로 보여준다. 정적인 통 속 캐릭터에 반복 몸짓은 넣지 않는다.

재질은 기존 스튜디오 조명과 반무광을 공유한다. 피규어 색: 피부 #efc7a2,
머리·검은 옷 #292d35, 회색 상의 #e4e1d9, 청바지 #587387, 백팩 #354253,
신발 #fff9ec, 사원증 줄 #63beb4. 여러 캐릭터는 공유 형상과 인스턴싱으로 그린다.
새 라이브러리·이미지 생성·서버/API 변경은 필요하지 않다.

## v10: 읽을 틈이 있는 미끄럼틀과 이어진 배관

사용자 피드백: 미끄럼틀에서 너무 많은 캡슐이 빠르게 나와 부딪혀 난장판이다.
개별 캡슐의 빠르고 불규칙한 구르기는 유지하고, 자동 배출을 약 2초 간격으로
줄인다. 굴러가는 캡슐은 하나, 열린 캡슐까지 최대 4개만 보여준다. 새 글은
과거 재생보다 먼저 내보내며 대기 중인 새 글을 버리지 않는다.

Layout: 기존 경기장과 입력부를 유지하고 장식 배관만 화면 가장자리로 연결한다.
위쪽 양 진영 파이프는 화면 끝까지 이어진다. 선택한 편은 입력구 → 화면 가장자리
→ 위쪽 통의 파이프까지 둥근 배관으로 연결한다. 3D 파이프 뒤끝의 투영 좌표를
사용해 화면 크기·스크롤·모바일 입력창 위치가 바뀌어도 접점을 맞춘다.
저장된 메시지 캡슐이 실제 배관 경로를 따라간 뒤 기존 3D 배출로 이어진다.
움직임 줄이기는 이동을 생략하고 결과를 표시한다. 새 의존성은 추가하지 않는다.

## v9: 편 방향으로 이어지는 전송 파이프

주 행동은 캡슐 버튼으로 메시지 보내기. 민트는 왼쪽, 코랄은 오른쪽에 투입구와
캡슐 버튼을 두고 투명한 운송 파이프를 해당 화면 가장자리까지 잇는다.
입력·글자 수·편 선택·받아치기·취소는 유지한다. 파이프는 조작을 가리지 않는다.
Layout: 경기장 입력부 - 기존 stack 안에서 투입구를 선택한 편 방향에 연결 -> stack
(https://github.com/changeroa/StyleGallery/blob/main/patterns/stacking/stack.md);
scroll owner: document; 파이프는 흐름 밖 장식이며 화면 가로 스크롤을 만들지 않는다.

캡슐 버튼은 기존 3D 캡슐처럼 투명한 위쪽, 편 색의 아래쪽, 얇은 이음선과 반사를
갖는다. 작성 중에는 작은 종이 안에 입력한 글 일부가 보인다. 저장 성공 후 종이가
140ms 동안 안으로 들어가고, 580ms 전송 동작 안에서 캡슐이 압축되어 입구를 지나
화면 끝으로 빠져나간 뒤 기존 파이프 배출로 이어진다. 입력은 기다리지 않고 계속된다.
beui button 소스의 상태 피드백·움직임 줄이기 원칙을 확인했으며, 경로 전송 자체는
기존 WAAPI로 만든 고유 연출이다. 새 모션 라이브러리를 추가하지 않는다.
움직임 줄이기는 이동을 생략하고 저장·배출 결과를 바로 표시한다.

## v8: 캡슐 투입구와 실제 파편 충돌

주 행동은 투입구에 한마디를 넣어 보내기. 경기장 → 투입구 → 선택한 의견과 기록
순서로 배치한다. 읽는 말풍선과 입력창이 겹치지 않게 한다. 편 선택, 글자 수,
원문 인용·취소, 전송 오류, 한글 조합과 줄바꿈을 유지한다.

Layout: 경기장 입력부 - 받침대 아래에 작성 동작 연결 -> stack
(https://github.com/changeroa/StyleGallery/blob/main/patterns/stacking/stack.md);
scroll owner: document; 고정 높이로 인용문을 자르거나 시각 순서와 탭 순서를 바꾸지 않는다.
모바일 입력 중에만 동일 폼을 visual viewport 하단으로 옮기고 자리 높이를 보존한다.
경기장이 화면 밖이면 전송할 때 경기장이 입력창 위에 보이도록 스크롤을 조정한다.

크림색 받침대, 내 편 색의 둥근 입구와 전송 버튼, 음각의 흰 입력 홈을 사용한다.
포커스 때 내 편 색이 은은히 드러나고 저장 성공 때만 0.24초 캡슐 투입 후 파이프가
이어진다. 받아치기에서는 입력 위치를 유지하고 원문 한 줄·취소를 붙인다.
움직임 줄이기에서는 투입 이동을 생략한다.

미끄럼틀 충격파와 범퍼 크기 애니메이션은 제거한다. 출구 위치·속도·회전·질량에
작은 편차를 주고 실제 충돌을 따른다. 앞 받침대에서 충분한 충돌이 생기면 부모
캡슐을 의자와 두 껍질의 강체로 교체한다. 파편은 중력·반발·마찰과 서로의 충돌로
멈추며 미리 정한 좌우 경로나 일정 시간 후 강제 고정을 쓰지 않는다. 같은 캡슐의
겹친 조각끼리의 초기 충돌은 제외하고, 다른 캡슐과 조각끼리는 충돌한다. 약하게
착지해 정지한 캡슐은 물리 수면 상태가 되면 열어 의견이 계속 대기하지 않게 한다.
슬롯 24개와 슬롯당 파편 3개로 수를 제한하고, 제거·재사용 때 물리 객체도 회수한다.

## v7: 빠르게 굴러와 앞 범퍼에서 열리는 캡슐

주 행동은 한마디 보내기. 출력 순서는 빠른 구르기 → 실제 앞 범퍼 충돌 →
껍질이 양옆으로 튀며 의견 표시다. 입력창 배치는 이번 변경에서는 제안만 남긴다.
기존 편 선택, 의견 본문, 받아치기, 지난 대화 구분과 정지 조작을 유지한다.

미끄럼틀 배출 초기 속도를 3.8에서 12.8로 높이고 회전을 이동 속도에 맞춘다.
시간만 지나면 중간에서 열리던 조건을 없앤다. 앞 범퍼 또는 그 바로 앞 캡슐과
충돌할 때 열고, 0.22초 동안 껍질을 펼친다. 부드러운 원형 충격파는 0.2초 동안
커졌다 사라진다. 장면 전체를 흔들지 않고 범퍼에만 작은 반동을 준다.
움직임 줄이기에서는 구르기·충격파 없이 열린 캡슐과 의견을 즉시 보여준다.
이 경로는 기존 Cannon 물리를 조정하는 고유 연출이며 새 모션 라이브러리를 쓰지 않는다.

## v6: 자리하나 캐릭터와 같은 부드러운 3D 재질

사용자가 카툰 렌더 v5를 먼저 커밋한 뒤 기존 캐릭터 사진 스타일을 요청했다.
실제로 확인한 기준 에셋은 `frontend/src/shared/assets/landing/landing-hero-chair.webp`,
`together-chairs.webp`, `frontend/src/shared/assets/illustrations/signup-crew.png`다.

공통 특징은 둥글고 도톰한 형태, 매끈한 반무광 재질, 넓고 부드러운 하이라이트,
진한 외곽선 없는 실루엣, 밝은 민트·코랄과 따뜻한 흰색, 은은한 그림자다.
3단계 toon 명암과 잉크 윤곽선 대신 물리 기반 재질과 스튜디오 환경광을 쓴다.
원본 이미지의 실시간 3D 재질 근사이며 원본 제작 파일을 복원한 것은 아니다.

파이프 수치·주장 클릭·넓은 통·기존 만화 받아치기 말풍선은 그대로 유지한다.

## v5: 큰 카툰 경기장과 간단한 편 선택 (보존 버전)

사용자 최신 요청: 의자 착석은 제거한다. 파이프 몸통에 표 비율, 바로 옆에 주장 글.
주장을 누르면 편 선택이 끝나고 체크와 편 색으로 상태를 보여준다. 별도 의자 버튼,
캐릭터 착석, 깃발 기둥은 쓰지 않는다. 한 사람 한 표와 편 변경, 의견 저장은 유지한다.

경기장 최대 폭을 1600px로 넓히고 통을 카메라에 더 크게 잡는다. 정확한 숫자는
파이프의 화면 좌표에 붙이고, 중앙 아래쪽은 충돌 말풍선용으로 확보한다.
모바일도 두 주장과 숫자를 항상 읽을 수 있게 크기와 줄바꿈을 조절한다.

3D 재질은 실제로 toon shading으로 바꾼다. 민트·코랄 기본색과 3단계 명암,
진한 녹색 윤곽선, 크림색 미끄럼틀, 반사 없는 옅은 유리로 만화 UI와 맞춘다.
의자 캡슐의 내용물과 물리 움직임은 유지한다. 새로운 라이브러리는 추가하지 않는다.

## 파이프 응원석 (v4, 보존 버전)

주 행동: 깃발 또는 의자를 눌러 내 편 고르기. 정보 우선순위는 두 주장 → 내 자리 → 투표 비율.
기존 두 카드와 별도 비율 막대를 없애고 깃발·의자·숫자를 파이프 위치에 붙인다.
선택지 전문, 정확한 표 수와 비율, 총 참여자, 현재 편, 재생 상태·정지 조작은 유지한다.

Layout: 파이프 응원석 - 3D 파이프에 투표 조작부 연결 → overlay-stack;
scroll owner: document; 파이프의 화면 좌표에 붙는 양쪽 조작부와 중앙 충돌 공간을 분리한다.
데스크톱 의자는 바깥쪽, 모바일 의자는 파이프 위쪽에 두어 충돌 말풍선과 겹치지 않는다.
레이아웃 기준은 기존 경기장과 layout-skill의 overlay-stack이며 새 화면·라우트는 추가하지 않는다.

깃발은 흰 천에 편 색의 접힌 끝과 굵은 글자, 의자는 기존 자리하나 형태의 민트·코랄이다.
선택한 의자에는 둥근 흰 캐릭터와 ‘나’ 표시. 투표 때만 0.5초 착석 동작과 짧은 파이프 팽창.
선택을 바꿔도 채팅이나 실제 표가 추가 생성되지 않는다. 줄바꿈 가능한 주장과 44px 이상
클릭 영역, 키보드 조작을 유지하며 움직임 줄이기에서는 캐릭터 위치를 즉시 갱신한다.

기존 흰 경기장·민트 `#2ac1bc`·코랄 `#ed6a5a`, 둥근 의자 캡슐을 유지한다.
주 행동은 의견을 골라 받아치기 전송. 시선 순서는 두 캡슐의 충돌 → 두 의견 → 작성자다.
원문, 답장, 편 색, 작성자, 지난 대화 여부, 펼치기와 닫기를 유지한다.

Layout: 기존 통의 충돌 지점에 고정된 두 말풍선과 작은 VS. 화면을 덮는 패널이나
새 레이아웃은 추가하지 않는다. 좌우 말풍선은 캡슐이 출발한 파이프 방향을 따른다.

## 만화 말풍선 수정

둥근 사각 알림 카드 같다는 피드백에 따라, 흰색 비대칭 풍선과 중앙 충돌을 향한
긴 꼬리로 바꾼다. 민트·코랄은 아래쪽 두께와 작은 의자 작성자 표시에 사용한다.
본문은 데스크톱 20px·모바일 14px의 굵은 글자로 먼저 보이게 한다.
‘눌러서 전체 보기’는 시각 안내에서 빼고 접근성 설명으로 유지한다.
VS는 원형 배지를 없애고 글자 자체로 두 풍선 사이에 놓는다.
0.46초 안에 충돌점에서 펼쳐져 살짝 튕긴 뒤 정착하고 기존 페이드아웃은 유지한다.

## 모션

- 양쪽 파이프에서 0.78초간 예비 동작과 가속, 0.12초간 충돌 압축 후 껍질이 벌어진다.
- 민트·코랄의 둥근 연기와 조각이 퍼지고 ‘퐁!’ 뒤에 VS와 두 말풍선이 남는다.
- 말풍선은 0.46초간 불투명도를 높이며 충돌 위치에서 펼쳐지고, 6초간 읽을 시간을 준다.
- 종료·닫기 모두 0.48초 페이드아웃 후 제거한다. 펼쳐 읽으면 닫을 때까지 유지한다.
- 움직임 줄이기에서는 이동과 폭발 없이 0.24초 페이드인으로 두 의견을 보여준다.
- beui tooltip의 등장/퇴장 생명주기와 reduced-motion 분리를 참고하되,
  충돌 경로는 기존 Three.js 연출을 수정한다. 새 애니메이션 의존성은 추가하지 않는다.

사용한다. 의견 저장과 투표 비율은 연출에 영향받지 않는다.
