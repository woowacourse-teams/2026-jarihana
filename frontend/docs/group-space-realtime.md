# 아지트 M1·M2 프론트 런타임

`features/group-space/realtime/`는 입장권 요청, WebSocket 연결, 상태 검증, 재연결과 원격 위치 보간을 담당한다. 기존 `/groups/:groupId` 아지트에서 이용 모드로 들어갈 때 연결하며 웹 미리보기와 꾸미기는 로컬 편집 상태를 유지한다. 프로젝터와 미디어 전송(M3)은 포함하지 않는다.

서버·DB·배포의 HLD와 가구·개인 아바타의 결정 이유는 [공통 아키텍처 문서](../../docs/clubhouse-realtime-architecture.md)에 있다. 입장권 자체는 기존 backend가 발급하며 이 프론트 모듈은 발급 API를 호출한다.

## 상태와 배치

- 입장·재접속은 REST 입장권을 새로 발급받고 첫 WebSocket 프레임에서 인증한다. 토큰을 URL 또는 저장소에 기록하지 않는다.
- 입장 snapshot에는 착석 슬롯, 보유 소품·잔량, 선반 물건, 문·조명·식물·제조 상태가 포함된다. 공유 행동은 서버 상태를 수신한 뒤 화면에 반영한다.
- 이동은 100ms 간격으로 전송하며 원격 캐릭터는 100ms 지연 보간한다. 이동과 제어 순서, room epoch, 연결 generation을 따로 검사한다. 같은 연결의 RESYNC는 이동 sequence를 초기화하지 않는다.
- 연결된 상태에서 `INVALID_MOVEMENT`·`LAYOUT_MISMATCH`를 받으면 소켓을 유지하고 뒤따르는 서버 스냅샷으로 보정한다. 이동 검증을 해제하는 처리는 아니다.
- `layoutRevision`이 바뀌면 저장된 방을 다시 읽는다. 새 배치가 준비되기 전에는 공유 행동과 새 배치의 원격 화면 적용을 막는다. 수정 중인 초안은 보존하며 취소하면 새 배치를 적용한다.
- 이전 배치에서 앉은 가구가 이동·삭제됐을 때 서버가 보내는 안전 위치와 서기 상태를 적용한다. 선반 소품은 서버의 새 world 좌표를 따른다. PLACE의 slot은 공통 런타임 surfaces 배열의 선반 층 index다.
- 연결 끊김 시 미확정 명령을 실패 처리하고 재연결 뒤 재전송하지 않는다. 권한 상실은 상태를 비우고 중단한다. 이전 `REALTIME_DISABLED` 응답을 받으면 로컬 이용으로 돌아가는 분기는 남아 있지만, 현재 backend는 별도 발급 활성화 플래그를 사용하지 않는다. 일반 네트워크 오류·권한 오류·배치 업그레이드 오류는 공유 행동을 차단한다.
- 다른 모임으로 이동하거나 꾸미기로 전환할 때, 화면을 떠나거나 로그아웃할 때는 `1000/LEAVE`로 명시적으로 퇴장한다. 서버는 좌석·보유 물건을 즉시 정리하며 비정상 연결 종료에만 재접속 유예를 적용한다. 종료 직전 ERROR 프레임을 받지 못하더라도 WebSocket 종료 사유의 오류 코드를 안내에 사용한다.

## 상호작용

기존 `E`·숫자키 메뉴에서 앉기/서기, 문 열기/닫기, 꺼내기/집기/반납, 선반에 놓기, 음료 제조/취소, 조명, 물 주기를 처리한다. `R`은 내려놓기, `G`는 던지기, `H`는 인사다. 소모품은 좌클릭 또는 먹기·마시기 버튼으로 소비한다. 책과 컵의 자세 선택은 실제 보유 물건을 기준으로 표시한다.

카메라/삼각대 촬영은 현재 WebGL 화면을 최대 1600px JPEG로 캡처한다. 미리보기의 '활동 기록에 첨부'에서 기존 ActivityPostComposer를 열고 사진을 전달한다. 업로드와 게시 요청은 사용자가 폼의 '공개하기'를 누를 때 시작한다.

## 표시 범위와 검증

멀티 입장 상태에 회원이 저장한 `avatarAppearance`가 있으면 내 캐릭터와 원격 캐릭터에 같은 아바타 관절과 부품을 사용한다. 걷기·뛰기·점프·인사·착석은 외형과 별도로 동작하며, 방에서 든 소품은 손의 위치를 따른다. 저장한 외형이 없는 회원은 기존 기본 캐릭터로 표시한다. 채팅 말풍선은 온라인 참여자의 실제 캐릭터에 붙인다.

단위 테스트는 같은 연결의 재동기화, 재접속의 명령 미재생, 배치 변경 중 명령 차단, 오래된 이동 프레임 무시, 늦은 입장 상태, 동일 시각 보간, 포즈 변경과 사진 첨부 시 자동 게시 금지를 검증한다. 실제 두 브라우저의 시각·연결 검증과 EC2 운영 확인은 별도다.
