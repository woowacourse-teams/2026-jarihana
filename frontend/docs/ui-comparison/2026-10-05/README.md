# UI 변경 비교 — 2026-10-05

## 촬영 조건

- AS-IS: https://dev.jarihana.com 에서 직접 촬영한 배포 화면.
- TO-BE: 이 브랜치의 production 모드 프론트엔드. 로컬 프록시로 같은 배포 환경의 공개 API를 읽고 쿠키를 제외해 양쪽 모두 로그아웃 상태로 맞췄다.
- 브라우저 크기 설정: 데스크톱 1440 × 1000, 모바일 390 × 844. 브라우저 도구가 반환한 이미지 크기는 각각 1425 × 990, 375 × 812다.
- AS-IS는 최초 PR 작성 때 촬영한 2026-10-05 배포 화면을 보존했고 TO-BE는 같은 날 후속 UI 수정까지 반영해 다시 촬영했다. 비교 쌍마다 화면 크기를 맞췄고 상세는 같은 모임(`/groups/101`)을 사용했다. 홈 한마디·시간대와 목록 데이터는 촬영 시점에 따라 달라질 수 있다. 하단 화면은 해당 영역이 보이는 위치까지 스크롤했다.
- 파일은 브라우저에서 받은 JPEG 바이트를 그대로 저장했다. 별도 편집이나 재인코딩을 하지 않았다.

## 비교 화면

| 파일 접두사 | 페이지 | 확인할 변경 |
| --- | --- | --- |
| home-desktop | `/` | 헤더, 본문 여백, 전체 너비 히어로, CTA, 검색 위치 |
| home-mobile | `/` | 모바일 헤더와 로고, 모서리, 히어로 배치 |
| archive-desktop | `/` 하단 | 카드 모서리, 아카이브 전체 보기, 본문과 푸터 경계 |
| ended-desktop | `/groups?status=ENDED` | 종료 배지, 이미지 명암, 모집 정보 표시 |
| detail-desktop | `/groups/101` | 상세 배경 오버레이, 헤더, 본문 여백 |
| detail-mobile | `/groups/101` | 상세 배경 오버레이와 모바일 배치 |

각 접두사 뒤의 `-before.jpg`가 AS-IS, `-after.jpg`가 TO-BE다.

## 로컬 데이터 예시

배포 환경에는 촬영 시점의 오늘 일정이 없어 홈 비교 사진에는 양쪽 모두 빈 상태가 보인다. 다음 사진은 `localhost:5173`의 개발 환경과 로컬 예시 데이터로 촬영했으며, 배포 화면과의 직접 비교 자료가 아니다.

- `today-example-local-desktop.jpg`: 1045 × 853 브라우저에서 다시 촬영한 순환 다이얼, 카드 한 줄 말줄임, 마감 표시와 작아진 자세히 버튼.
- `hero-preview-local-desktop.jpg`: 최초 PR 시점에 촬영한 개발 환경 전용 시간대·이미지 세트 선택 UI와 밤 배경. 최신 헤더·버튼 크기 비교에는 사용하지 않는다.
- `header-create-profile-local.jpg`: 최신 헤더의 의자 이미지가 있는 자리 만들기 버튼과 가는 프로필 화살표. 1045px 브라우저에서 상단 440px만 촬영한 로그인 상태 예시다.
- `recruiting-layout-local.jpg`: 유형 배지를 제목 위로 옮기고 참여 인원과 남은 자리를 같은 행에 둔 최신 홈 카드. 1045 × 853 브라우저에서 촬영했다.

정지 이미지는 전환 애니메이션의 타이밍을 보여주지 않는다. 탭 이동, 카드에서 상세로 이동, 목록 복귀는 별도 브라우저 동작 확인 대상이다.
