# 회원 아바타 화면

`tests/e2e/avatar.spec.js`가 프로덕션 빌드와 테스트 전용 API fixture를 사용해 촬영한 화면이다. 실제 회원 데이터는 포함하지 않는다.

- `avatar-mypage-desktop.png`: 프로필 아래 아바타와 편집 진입점.
- `avatar-editor-desktop.png`: 1280px 파츠 편집, 상시 표시 추천 조합.
- `avatar-editor-mobile.png`: 390px 전신 미리보기와 파츠 편집.

아바타 편집은 신규 화면이므로 이전 편집 화면 캡처는 없다. 이전 마이페이지는 프로필 아래 정적 장식만 제공했다.
