# 자리하나 회원가입 보충 이미지

기존 `signup-crew.png`, `signup-coach.png`의 둥근 얼굴, 단순한 표정과 부드러운 3D 클레이 질감을 기준으로 제작한 이미지다.

## 파일

| 파일 | 용도 | 구분 요소 |
| --- | --- | --- |
| `signup-bootcamp.png` | 부트캠프 소속 카드 | 민트 후드, 헤드폰, 태블릿과 펜 |
| `signup-company.png` | 회사 소속 카드 | 하늘색 셔츠, 베이지 바지와 텀블러 |
| `signup-others.png` | 시안 A의 그 외 카드 | 코치, 부트캠프 수강생과 현직자의 묶음 |
| `signup-complete.png` | 공통 가입 완료 화면 | 민트 의자, 체크 토큰과 작은 축하 장식 |
| `icons/affiliation-crew.svg` | 크루 소속 아이콘 | 백팩 |
| `icons/affiliation-coach.svg` | 코치 소속 아이콘 | 설명 보드 |
| `icons/affiliation-bootcamp.svg` | 부트캠프 소속 아이콘 | 코드 태블릿 |
| `icons/affiliation-company.svg` | 회사 소속 아이콘 | 서류 가방 |
| `icons/wooteco-logo.svg` | 우테코 크루 인증 버튼 로고 | 가운데 채운 원, 같은 중심의 얇은 고리, 고리 위 대각선 양 끝의 작은 원 두 개 |

PNG 4종은 각각 1254 x 1254 크기이며 투명 알파 채널을 포함한다. 흰색과 옅은 민트색 배경에서 사용하며, `object-fit: contain`으로 전신과 소품을 유지한다. 기존 그림과 함께 사용할 때에는 같은 정사각형 이미지 영역에 배치한다. 캐릭터는 160~240 CSS px, 묶음 그림은 180~280 CSS px, 가입 완료는 120~240 CSS px를 권장한다.

소속 아이콘 SVG는 `24 x 24` viewBox, `1.75` 선 두께, 둥근 선 끝과 `currentColor`를 사용한다. 우테코 로고는 같은 viewBox에 `currentColor` 채움을 쓰고, 고리는 `vector-effect="non-scaling-stroke"`로 표시 크기와 관계없이 1.5px 두께를 유지한다. 검은 배경 버튼 안에서는 흰색으로 쓴다. 인라인 SVG로 넣으면 부모의 `color`를 따르며, 외부 파일을 `img`로 불러오면 기본 검정으로 표시된다. 옆에 소속 이름이 있으면 아이콘은 `aria-hidden="true"` 또는 `alt=""`로 처리한다. 단독으로 사용하는 인라인 SVG의 제목 ID는 페이지에서 중복되지 않도록 조정한다.

## 확인과 재사용

- `preview.html`을 열면 기존 캐릭터와 새 이미지, 투명 영역, 소속 아이콘을 함께 볼 수 있다.
- 원본 이미지 생성에는 내장 `image_gen` 도구를 사용했다. SVG는 직접 작성했다.
- 최종 생성 프롬프트와 참조 파일은 `prompts.json`에 보관한다.
- 자산 추가 범위의 작업이며, 서비스 가입 화면이나 API 계약에는 연결하지 않았다.

게시된 Claude 시안 링크는 자동으로 읽을 수 없었다. 사용자에게 제공받은 시안 설명과 저장소의 실제 이미지를 기준으로 제작했다.

## 검증 결과

- PNG 4종의 디코딩, 1254 x 1254 크기, RGBA와 투명 알파 채널을 확인했다.
- SVG 4종의 XML 구문, viewBox와 공통 선 속성을 확인했다.
- 우테코 로고 SVG는 XML 구문, 모든 원이 24 x 24 영역 안에 있는지, `img`로 160px, 48px, 18px 렌더링한 모양을 확인했다.
- Edge에서 미리보기를 1280px와 390px 너비로 렌더링했다. 모든 이미지 로딩과 가로 넘침 없음을 확인하고 데스크톱, 모바일 캡처를 검수했다.
- 서비스 실행 코드를 변경하지 않아 Jest, lint와 서비스 빌드는 실행하지 않았다.
